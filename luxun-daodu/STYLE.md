# 《铁屋与路：鲁迅名篇历史导读》写作规范（所有作者必读）

## 读者画像
一位成年读者，读过鲁迅几篇课文，对个别金句（如《故乡》结尾"希望本无所谓有……"）有触动，但对整篇的结构、意图、思想"没有感觉"。他要的是：先懂时代，再懂文章；不是只赏析金句，而是带着他把整篇从头读到尾，读懂鲁迅为什么这样写、整篇在说什么。

## 全书结构（共 10 位作者分写，按顺序拼接）
- 00 序章 + 第一部 大时代：1840—1936 的中国与世界（总背景）
- 01 第二部 从绍兴到仙台：鲁迅的来处（《朝花夕拾》选）
- 02 第三部（上）铁屋中的呐喊：《呐喊·自序》《狂人日记》《孔乙己》《药》
- 03 第三部（中）故乡与看客：《故乡》《风波》《一件小事》《社戏》
- 04 第三部（下）《阿Q正传》
- 05 第四部（上）彷徨：《祝福》《在酒楼上》《伤逝》
- 06 第四部（下）孤独者们：《孤独者》《肥皂》《娜拉走后怎样》
- 07 第五部 野草：鲁迅的内心
- 08 第六部 北京的血与墨：杂文（1925—1926）
- 09 第七部 上海十年 + 尾声

## 每篇作品的固定写法（核心要求）
1. **## 篇名**（二级标题），下面一个小信息行：写作/发表时间、收入集子。
2. **### 写在阅读之前**：这篇写于什么时候、鲁迅当时处境如何、那一年中国/世界在发生什么，和这篇有什么关系。要把大历史和这一篇具体挂钩，不要泛泛重复总背景。
3. **### 带读原文**：把原文按自然段落切成若干"段落组"，读者会在微信读书里同时打开《鲁迅全集》原文对照。每组格式：
   - 先用 fenced div 给出"原文定位与摘引"：
     ```
     ::: yuanwen
     **第 3—6 段**（从"我冒了严寒……"起，到"……这只是我自己心情的改变罢了"止）

     这几段写……（用 2—4 句话概述这一组原文写了什么）

     关键句："……"
     :::
     ```
   - 紧接着是解读：
     ```
     ::: jiedu
     解读文字……
     :::
     ```
   - 解读要讲：这一段在全篇结构中起什么作用；关键词、典故、方言、旧制度名词的解释；人物心理；鲁迅的笔法（白描、反讽、留白、对照）；与他别的作品或生平的呼应。解读要充分展开，是全书的主体。
4. **### 通篇回看**：从整体结构上复盘全篇（可以用"第一层……第二层……"），讲清这篇的核心思想，并指出读者常见误读（例如只记住金句）。
5. **### 延伸思考**：2—4 个值得读者自己想的问题，或推荐对读的篇目。

## 引用原文的硬性限制（非常重要，违反会导致任务失败）
- 绝对不要大段逐字抄录原文。每个段落组的"关键句"只摘一到两句，每次引用不超过 60 字；全篇累计的直接引用要远少于原文篇幅。其余一律用你自己的话概述。
- 解读中引用原文词句也要短（几个字到一句），用引号标出。
- 引用必须是你有把握的原文；没把握就只概述、不加引号。
- 段落定位用"第几段"加起止句的前几个字即可，起止句各不超过 12 字。

## 历史背景写法
- 史实要准确（年份、人名、事件）。不确定的细节不要硬写。
- 把世界局势和中国局势串起来讲：比如日俄战争在中国东北打、一战与巴黎和会、十月革命、日本的明治维新与对华政策、大萧条、九一八等。
- 讲历史时多用具体的人和场景，少用教科书式口号。

## 文风
- 中文，像一位懂行又健谈的老师在带读，亲切、有洞见、敢下判断，但不油滑，不用网络流行语。
- 不要空洞拔高（避免"深刻揭露了封建礼教吃人的本质"这类套话堆砌），每个判断都要落到文本细节上。
- 标点全部用全角中文标点；引号用""和''，禁止用「」『』。英文、年份数字照常。
- Markdown：使用"**粗体小标题**+解释"时，两者之间必须空一行；或者用"- **标题**：解释"的列表写法。不要用表格（电子书阅读器显示不佳）。
- 标题层级：作者文件的最高级用 `#`（部的标题，每个文件开头一个），每篇作品用 `##`，篇内小节用 `###`。不要用 `####` 以下层级。

## 字数
- 每位作者的文件目标约 2 万字（几乎全是你自己写的解读与背景），宁多勿少，但不要注水。

## 输出
- 写入指定的 Markdown 文件（UTF-8）。可以分多次写入/追加，完成后自检一遍：fenced div 是否成对闭合（`::: yuanwen` / `::: jiedu` 与 `:::`）、标点是否全角、有没有「」。
- 请分多次写入（每次写入一篇作品或一个大节，用追加方式），不要一次写入整个文件。
- 完成后回报：文件路径、大致字数（用 `wc -m` 统计）。
