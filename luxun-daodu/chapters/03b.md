## 风波

写于1920年8月，初刊《新青年》第八卷第一号（1920年9月），收入《呐喊》。

### 写在阅读之前

1917年7月1日清晨，北京城里的人一觉醒来，发现街上又挂起了龙旗。“辫帅”张勋带着他那支至今还留着辫子的“定武军”进京，把十二岁的废帝溥仪重新扶上了宝座，康有为也跑来凑热闹。这场闹剧只维持了十二天，段祺瑞在马厂誓师，讨逆军一到，辫子兵四散，张勋躲进荷兰使馆。北京的市民后来回忆，那几天最抢手的生意是假辫子，剃了头的人赶紧买一条挂上，复辟一失败，假辫子又扔得满街都是。

鲁迅当时就在北京教育部做佥事。复辟发生后，他愤而离职，复辟平定后才回部里。所以这件事他不是从报纸上看来的，而是亲身经过。可是三年之后他写《风波》，偏偏不写北京，不写张勋，不写段祺瑞，而是把镜头拉到浙东一个临河的小村子，看这场惊动全国的政变，传到最底层时变成了什么样子。

答案是：变成了一条辫子的问题。

要懂这一点，得先懂辫子在近代中国的分量。清初入关，以“剃发令”逼汉人改换发式，辫子从此成了臣服的标记。到了晚清，留学生在东京剪辫，是一种政治表态；鲁迅自己1903年在弘文学院就剪了辫子，回国后还因为没辫子被人叫作“假洋鬼子”，在街上受人嘲骂。辛亥革命之后，各地又有强行剪辫的风潮。换句话说，一个普通中国人的后脑勺，二十年里被政权反复摆布：先是不留就杀头，后来留着就算顽固，再后来，复辟一来，没留的又可能惹祸。鲁迅后来在一篇文章里感慨，自己对辫子的事有切肤之痛，原因就在这里。

1920年写这篇小说时，五四运动刚过去一年，《新青年》正在分化，北洋政府走马灯似的换内阁，直皖战争在这年夏天打响，段祺瑞败下阵来。上层政治翻来覆去，鲁迅关心的却是另一个问题：这么多“革命”“共和”“复辟”，到底在农民的生活里留下了什么？《风波》就是他给出的一份冷静的田野报告。

### 带读原文

::: yuanwen
**第一部分**：开头的临河场景，夕阳下各家在土场上摆桌吃饭，船上路过的文人对此大加赞叹。

关键句：九斤老太的口头禅“一代不如一代”。
:::

::: jiedu
小说一开场像一幅风俗画：河边土场，太阳收尽了余晖，乌桕树叶干巴巴的，花脚蚊子嗡嗡地飞，农家把小桌矮凳搬出来吃晚饭。紧接着鲁迅安排了一个外来的观察者：坐在酒船上的文豪，看见这光景，诗兴大发，赞叹田家生活无忧无虑、真是乐事。

这一笔是全篇的第一个反讽。文豪看到的是“画”，读者马上要看到的是“人”：老人在抱怨，女人在骂孩子，男人带回一个让全家吓得吃不下饭的消息。所谓田园之乐，是隔着一条河、坐在船上才看得见的风景。鲁迅讨厌那种把农村当作山水小品来欣赏的文人趣味，这里只用一句话就把它戳破了，而且不加评论，任文豪的船径直开过去。

然后是九斤老太。她七十九岁，坐在那里破芭蕉扇一扇，嘴里不停地念叨世道变坏。最妙的是村里人的名字：九斤老太、七斤、六斤，一代比一代出生时轻，仿佛连体重都在印证她的牢骚。这是鲁迅式的冷幽默，他借这家人的取名习惯（按出生时的斤两起名，在浙东乡间确有其俗），把一种保守的历史观变成了可以称量的笑话。九斤老太的“一代不如一代”，并不是什么深思熟虑的复古主张，而是一个老人对一切变化的本能反感。可正是这种本能，在复辟的消息到来时，会自然而然地站到“老规矩”那一边。
:::

::: yuanwen
**第二部分**：七斤从城里撑船回来，带回了皇帝重新坐朝的消息，全家顿时为他没有辫子而发愁。

关键句：“皇帝坐了龙庭了。”
:::

::: jiedu
七斤是村里的“出场人物”。他每天撑航船往返城乡，因而见过世面，知道些城里的新闻，在村人眼里算得上一个有见识的人。鲁迅特意交代，他的辫子是几年前进城时被人剪掉的。注意这个被动：七斤并没有什么革命觉悟，他的辫子是在辛亥年的剪辫风潮里稀里糊涂丢掉的。历史在他身上动了一刀，他自己并没有参与决定。

现在历史又转了个身。皇帝坐了龙庭，传说要辫子，于是这条丢掉的辫子成了要命的东西。七斤嫂的反应极有层次：先是吃惊，接着埋怨丈夫，再接着越想越怕，把火气撒到孩子和邻居身上。她骂七斤的那些话，粗野又带着哭腔，鲁迅照录绍兴口语，读来活灵活现。这里你要看见一个女人的处境：她没有能力判断皇帝是真是假，也不知道城里到底发生了什么，她能做的只是把恐惧转成咒骂，在家里找一个可以责怪的对象。

还有一个细节值得先记下：在稍后赵七爷到场的那阵混乱里，七斤嫂迁怒于女儿六斤，六斤手里的空碗落地，碰出一个大缺口，七斤又给了孩子一巴掌。碗后来被拿到城里补上铜钉，一直用到故事结束。这只碗是全篇的小道具，“风波”在它身上留下了唯一看得见的痕迹。
:::

::: yuanwen
**第三部分**：赵七爷穿着宝蓝色竹布长衫走过独木桥来到土场，用《三国》和“长毛”的旧事恐吓七斤一家，邻居八一嫂劝解反遭抢白。

关键句：赵七爷翻出的老话“留发不留头，留头不留发”。
:::

::: jiedu
赵七爷是全篇写得最精彩的人物。他是邻村茂源酒店的主人，方圆三十里内唯一的“学问家”，学问的全部来源是一部金圣叹批评的《三国志》（其实是《三国演义》），常常坐着一个字一个字地读，能说出五虎将的姓名甚至表字。鲁迅用这样一个细节，就把乡村知识分子的成色交代清楚了：他的“历史知识”来自演义小说，他的政治判断也只能套用说书人的逻辑。所以他会把张勋称作张大帅，再把张大帅附会成张翼德的后代，说他有万夫不当之勇，谁能抵挡得住。复辟这种关乎国体的大事，在他嘴里成了一段评书。

更要紧的是那件竹布长衫。鲁迅特别交代，赵七爷平时不穿它，三年来只穿过两次：一次是和他怄气的麻子阿四病了，一次是曾经砸过他酒店的鲁大爷死了。现在是第三次。这件长衫是他的“晴雨表”，专在仇人倒霉时穿出来。由此可见，他关心复辟，不是关心国家，而是看到了报私仇的机会：七斤曾经骂过他，现在七斤没了辫子，正好落在他手里。政治风向一变，乡村里积攒的小怨小恨立刻找到出口。

还有他的辫子。革命时他把辫子盘在头顶，像道士一样，以备两头都不得罪；如今皇帝回来了，他便把辫子放下来。一盘一放，就是一个乡绅的全部政治哲学：不站队，只看风。

然后是“长毛”的典故。太平天国时，太平军蓄发不剃，被称为“长毛”，清廷以剃发为顺民标志，民间于是流传“留发不留头”的惨痛记忆。赵七爷把这段六十年前的旧账翻出来，意思是改朝换代时，头发和脑袋只能保一样。他未必真信七斤会被杀头，但他享受这种恐吓的快感。土场上的人一听，都觉得七斤这回完了，没人替他说话，倒有不少人隐隐觉得解气。

只有八一嫂出来打圆场，说了几句公道话，结果被正在气头上的七斤嫂抢白了一顿。这一笔很辛酸：唯一的善意被当事人自己挡了回去。恐惧让人分不清谁是对手、谁是帮手。
:::

::: yuanwen
**第四部分**：此后几天七斤一家惶惶不安，村人对他们的态度冷了下来，七斤嫂盼着赵七爷再从门前走过时看他穿不穿长衫。
:::

::: jiedu
这一部分篇幅不长，却把“看客”和“谣言”的机制写透了。村里人并不真正知道城里发生了什么，他们获取信息的唯一渠道，一是七斤这样进城的人，二是赵七爷这样“有学问”的人。消息在传递中被人的利害和情绪层层加工：皇帝要辫子，没辫子要杀头，杀头还要按《三国》里的规矩来。没有人去核实，也没有办法核实。

村人的态度变化很微妙。七斤原本因为常进城、见识多而在村里有些体面，现在一下子成了危险人物。大家不一定恨他，但都乐于离他远一点，也乐于看这家人着急。这就是鲁迅在《呐喊·自序》里说过的看客：他们不是凶手，只是围观，可是围观本身就构成一种压力。

最传神的是七斤嫂的“观测法”。她判断天下大势的办法，是看赵七爷身上有没有那件长衫。这个细节既可笑又可悲：一个国家的政体问题，在一个农妇那里只能通过一件衣服来读取。可是你细想，她其实很聪明，她找到了最准确的信号，因为赵七爷的长衫确实比任何报纸都更灵敏地反映着乡村里的权力风向。
:::

::: yuanwen
**第五部分**：过了些日子，赵七爷又走过门前，却没穿长衫，辫子也重新盘上头顶，七斤一家放下心来，生活恢复原样，六斤已经缠了脚。
:::

::: jiedu
风波就这样无声无息地过去了。没有人告诉村民复辟失败了，他们是从赵七爷的头顶读出来的。七斤重新得到村人的尊敬，七斤嫂对他也恢复了相当的客气，九斤老太也做过了八十大寿，身子照样硬朗，牢骚照样满腹。

结尾最重的一笔落在六斤身上：她的双丫角已经梳成一条大辫子，新近又缠了脚，捧着那只钉满铜钉的饭碗，在土场上一瘸一拐地走。这短短一句里藏着全篇的答案。民国已经六年，共和的招牌还挂着，可是一个小女孩照样要缠足，照样要按老样子长大。那只碗被补好了，生活被补好了，所有的裂缝都钉上了铜钉，看上去完整，其实只是把伤口固定了下来。

所谓“风波”，原来连一点涟漪都没留下。鲁迅在这里的冷静近乎残酷：他没有让任何人觉醒，也没有让任何人受到真正的惩罚，而是让一切照旧。这比悲剧更让人心凉。
:::

### 通篇回看

《风波》的结构是一个圆：从土场上的晚饭开始，到土场上的日常结束，中间鼓起一个包，又平复下去。可以分三层看。

第一层是“隔”。开头的文豪隔着河看田家乐，结尾的读者隔着时间看一切照旧。政治中心与乡村之间也隔着：北京的复辟传到这里，只剩一句“皇帝坐了龙庭”，连皇帝是谁、为何坐上又为何下来，没人知道也没人关心。

第二层是“辫子”。在这个村子里，国体、共和、宪法这些词统统不存在，政治被压缩成一个最具体也最荒唐的问题：你的头发长还是短。辫子之所以要紧，是因为它背后是两百多年的暴力记忆。农民对政治的全部经验，就是权力会在你身上动手。

第三层是“照旧”。风波过后，没有任何东西被改变。这是鲁迅对辛亥以来十年历史的判断：上面换了无数招牌，底下的生活方式、人际关系、对孩子的处置，一点没动。

常见的误读，是把《风波》读成一篇讽刺“农民愚昧”的小说。其实鲁迅的笔锋更多指向赵七爷这样的乡绅，和那个坐船路过的文豪。七斤一家的愚昧是被处境决定的，他们没有消息来源，没有判断工具，只能靠一件长衫来猜天下。真正可怕的是，每一次“革命”都没有把这些工具交到他们手里。

### 延伸思考

- 把《风波》和鲁迅的《头发的故事》（1920）对读。后者借一位N先生之口，直接讲了剪辫的辛酸，可以看作《风波》的“议论版”。
- 赵七爷的长衫、孔乙己的长衫，都是鲁迅笔下的“身份符号”。两件长衫分别说明了什么？
- 结尾六斤缠脚的细节，为什么放在最后？如果删掉，这篇小说会失去什么？

## 一件小事

最初发表于1919年12月北京《晨报》周年纪念增刊，收入《呐喊》（集中篇末署1920年7月）。

### 写在阅读之前

这是《呐喊》里最短的一篇，不到一千字，常被选进中学课本，也常被读成一篇“歌颂劳动人民”的作文范本。要读出它的分量，得先看看1918到1919年的北京知识界在想什么。

1918年11月，一战协约国胜利的消息传到北京，城里放假庆祝，北京大学校长蔡元培在天安门前发表演说，喊出了“劳工神圣”。在他看来，这场战争是靠无数华工在欧洲战场挖战壕、搬弹药才赢下来的（北洋政府曾以“以工代兵”的方式派出十几万华工赴法），未来的世界属于劳动的人。这四个字一时风行。差不多同时，《新青年》上胡适、沈尹默都写过以人力车夫为题的新诗。人力车夫是北京街头最常见的劳工形象，坐车的知识分子每天都要面对一个问题：我坐在车上，他在前面拉，这算什么关系？

鲁迅的处境也值得一提。他从1912年随教育部北上，到写这篇时已在北京住了七八年。他是部里的官员，又是《新青年》的作者，每天上下班常坐人力车。小说里那件事，发生在民国六年的冬天，正是张勋复辟、对德宣战、府院之争的一年。那一年的“国家大事”多得令人眼花，鲁迅偏偏说，它们都没在自己心里留下什么，倒是一件路上的小事，让他念念不忘。

这篇小说的真正对象，不是车夫，而是坐车的“我”。

### 带读原文

::: yuanwen
**第一部分**：开头的总述，“我”说进京六年来耳闻目睹的国家大事都没在心里留下什么，只有一件小事意义不同。
:::

::: jiedu
开头像一句随口的感慨，其实是全篇的论点，而且是一个相当激烈的论点。六年里的“国家大事”指什么？袁世凯称帝、护国战争、张勋复辟、府院之争，每一件都上过报纸头版。鲁迅说它们只是增长了自己的坏脾气，让他越来越看不起人。

为什么大事不留痕迹？因为这些大事彼此相似：一群人上台，一群人下台，口号一换，里子不变，看多了只剩厌倦。这和《风波》的结论是一致的。而那件小事之所以留下来，是因为它第一次让“我”看见了自己。大事是别人的戏，小事却照出了观众席上的那张脸。
:::

::: yuanwen
**第二部分**：民国六年冬天一个大风的早晨，“我”坐人力车出门，车把带倒了一位老女人，“我”断定她并没有受伤，催车夫快走。
:::

::: jiedu
这一段的心理描写极其诚实，诚实到让人不舒服。风很大，路上几乎没人，一个花白头发、衣衫破旧的老女人从路边横穿过来，车夫让开了，她那件没扣好的棉背心兜着风，还是挂在车把上，慢慢倒地。

“我”的第一反应不是关心，而是判断：她摔得不重，又没人看见，车夫多事，自己要误事了。甚至进一步想，她是装的，想讹人。注意这一串念头的速度之快、逻辑之“合理”。这正是一个受过教育、见惯世故的城里人的反应。他不是坏人，他只是精明，精明到把一个摔倒的老人首先看成一桩麻烦。

鲁迅没有给“我”留任何面子。他把这种心理一字一句摊开，而不是事后美化。这是全篇最可贵的地方：自省的前提，是先承认自己真实的念头有多不堪。
:::

::: yuanwen
**第三部分**：车夫不理会“我”，扶起老女人，搀着她向前面的巡警分驻所走去，“我”望着他的背影，感到一种异样。

关键句：车夫的背影在“我”眼里“须仰视才见”。
:::

::: jiedu
这是全篇的转折点，也是鲁迅用笔最省的地方。车夫没有说一句漂亮话，他只是听老女人说摔坏了，便放下车，扶她走。他没有想过会不会被讹，没有想过误了生意，更没有想过车上的乘客怎么看。

“我”的感觉随之发生了一个奇特的变化：车夫满身灰尘的背影忽然变得高大，越走越大，要仰起头才看得见。这当然不是物理的描写，而是心理的倒转。坐在车上的人原本居高临下，拉车的人原本在下面、在前面、在弯腰；现在一切倒过来，坐着的人觉得自己矮下去了。

接下来那句话更重：这背影对“我”渐渐成了一种威压，几乎要榨出“皮袍下面藏着的‘小’”来。皮袍是体面的冬衣，是读书人、官员的身份；皮袍下面藏着的，是自私、冷漠和精明。“小”字加了引号，意思是一种人格上的矮小。鲁迅用的动词是“榨”，说明这种东西藏得很深，不用力挤不出来，而车夫的一个背影就做到了。
:::

::: yuanwen
**第四部分**：巡警出来告诉“我”另雇车，“我”不假思索地掏出一大把铜元请他转交车夫，随即开始追问自己这样做的意思。
:::

::: jiedu
这一段常被读者匆匆跳过，其实最见鲁迅的冷峻。“我”被车夫的背影压得透不过气，下意识做了一件事：掏钱。一大把铜元，请巡警交给车夫。

这一把铜元是什么？是补偿，是奖赏，还是赎罪？“我”自己也说不清，于是在路上反复问：难道是奖他？我能裁判车夫吗？这一追问非常要紧。给钱是知识分子面对劳工时最容易采取的姿态，它让施与者在一瞬间恢复了高位：我仍然是付钱的人，你仍然是收钱的人。鲁迅不肯让“我”用一把铜元把内心的不安打发掉，他让“我”意识到，这个动作本身又是一次“皮袍下面”的流露。

自省到这里，已经从“我当时想错了”推进到“我连补救的方式都是错的”。这是一种不给自己留退路的自省。
:::

::: yuanwen
**第五部分**：结尾回到当下，“我”说文治武力都像幼时读过的书一样忘了，只有这件小事常在眼前，并让他惭愧、促他自新。

关键句：这件小事“教我惭愧，催我自新”。
:::

::: jiedu
结尾把开头的论点收回来。“文治武力”指的就是那些国家大事，政客的文告和军阀的战争；鲁迅说它们在自己心里，就像小时候被逼着背过的“子曰诗云”，背过了，也就忘了。这个比喻很刻薄：堂堂国家大事，和私塾里不知所云的经书一样，与人心毫无关系。

而那件小事为什么不忘？因为它涉及的不是谁上台谁下台，而是一个人在一瞬间怎样对待另一个人。这才是鲁迅眼里真正的“大事”。他一生关心的“国民性”，归根到底就是这种日常的、细小的、彼此对待的方式。

还要注意，鲁迅最后说的是“惭愧”和“自新”，不是“感动”和“歌颂”。车夫在这篇小说里与其说是一个被赞美的英雄，不如说是一面镜子。他朴素的善意本身并不稀奇，稀奇的是“我”这样的人居然需要被它照醒。
:::

### 通篇回看

《一件小事》的骨架只有两层，一大一小，一外一内。

第一层是大与小的颠倒。开头说大事无痕，结尾说小事难忘，中间用一个具体场景证明这个颠倒为什么成立。鲁迅的判断是：民国以来的政治变动没有触及人心，而人与人之间的一个瞬间，却能撼动一个人对自己的认识。

第二层是上与下的颠倒。坐车的人和拉车的人，在物理上、经济上、文化上都是一上一下。车夫的背影“高大”起来，“我”的皮袍下面露出“小”来，社会位置与道德位置在这一刻错开了。这正是五四一代知识分子开始面对的问题：启蒙者是否天然站在被启蒙者之上？

读者最常见的误读，是把它读成“劳动人民品质高尚”的颂歌。那样读会错过鲁迅的锋芒。他写的是自我解剖，而且解剖得很彻底，连掏钱的动作都不放过。鲁迅后来说过，他解剖别人，更多的是更无情地解剖自己。这篇小说就是一次早期的公开示范。

另一种误读是认为这篇“太简单”。它确实简单，但在《呐喊》里有特殊的位置：别的篇目里，“我”多半是旁观者、叙述者，这一篇里，“我”第一次成了被审视的对象。后来《故乡》《祝福》里那个面对闰土、面对祥林嫂而无言以对的“我”，在这里已经露出了端倪。

### 延伸思考

- 找来胡适的新诗《人力车夫》对读。胡适写的是坐车人的同情与犹豫，鲁迅写的是坐车人的惭愧。两者的差别在哪里？
- 如果车夫当时听了“我”的话，拉起车就走，这件事还会被“我”记住吗？
- 鲁迅后来在《祝福》里，面对祥林嫂关于魂灵的追问而支吾逃开。这个“我”和《一件小事》里的“我”是同一种人吗？

## 社戏

写于1922年10月，初刊《小说月报》第十三卷第十二号（1922年12月），收入《呐喊》。

### 写在阅读之前

《呐喊》初版的最后一篇原本是取材神话的《不周山》，后来鲁迅把它抽掉（改题《补天》收入《故事新编》），《社戏》便成了这本集子的压卷之作。一本从“铁屋子”和“吃人”开始的书，最后停在一个夏夜的小船上，月光、豆香、笛声，这本身就很耐人寻味。

1922年的鲁迅住在北京西直门内的八道湾，和弟弟周作人一家同住。这一年春天，俄国盲诗人爱罗先珂寄住在他们家里，抱怨北京寂寞得像沙漠，鲁迅为此写了《鸭的喜剧》。北京这年也不太平，四五月间直奉两系军阀在京津一带开战，战火逼近城郊。政府长期欠薪，教育部的职员领不到全薪，鲁迅不得不靠兼课和稿费补贴家用。北京给他的感觉，很难说是愉快的。

要读《社戏》的前半，还需要知道京剧在当时的地位。民国初年，京剧正处在鼎盛期，“伶界大王”谭鑫培（艺名小叫天）号称一时无两，他1917年去世后，梅兰芳迅速走红。看戏是北京上流社会最重要的社交活动之一。与此同时，新文化阵营对旧戏颇不以为然：1918年《新青年》专门出过一期“戏剧改良”号，胡适、傅斯年等人批评旧戏程式僵化、不近人情，和捧角的张厚载等人展开过笔战。鲁迅没有直接参与那场论战，但他对京剧的态度是一贯的冷淡，后来还写过文章讥讽男旦艺术。

所以《社戏》的开头不是闲笔。它把“京城的戏”和“乡下的戏”并排放着，前者是热闹、拥挤、被吹捧的文化中心，后者是破旧、简陋、在乡村河边临时搭起的草台。鲁迅要问的是：哪一种才是“好戏”？而这个问题背后，还有一个更深的问题：那种“好”，到底在戏里，还是在别的什么地方？

### 带读原文

::: yuanwen
**第一部分**：“我”说二十年来只看过两回中国戏，都在北京，第一回在戏园里被锣鼓声震得头昏、找不到座位，挤了一阵便退了出来。

关键句：戏园里的锣鼓“冬冬喤喤”。
:::

::: jiedu
开头的语气是自嘲式的牢骚，带着一点漫画味。戏园里人挤人，锣鼓震耳，台上红红绿绿一闪一闪，“我”好不容易在一条长凳上找到空隙，凳子却高得离奇，坐上去像受刑，只好逃走。鲁迅写这些毫不客气，京城文化的中心在他笔下变得局促、嘈杂、不近人情。

注意“我”对这种不适的处理：他没有去分析京剧的艺术得失，只写身体的感受，头昏、耳鸣、腿悬空。这种写法很聪明，避开了理论之争，却让读者直接感到一种排斥感：这个地方不欢迎“我”，“我”也不属于这里。
:::

::: yuanwen
**第二部分**：第二回是为湖北水灾募捐的义务戏，“我”为了看小叫天买票进场，等了大半夜，台上不断换人，小叫天始终不出来，“我”终于离开；随后提到一本日本书论中国戏宜于野外远看。
:::

::: jiedu
第二回看戏，写得比第一回更细，也更好笑。“我”花钱买了票，本意是去看名角，结果从晚上等到半夜，看了一出又一出不认识的戏，尤其是一位老旦坐在台上唱个没完，“我”越等越焦躁，最后在拥挤和疲倦中退出，走到外面，夜气清爽，才觉得透过气来。

这里的“小叫天”就是谭鑫培。名角压轴，观众为他忍受漫长的等待，这正是捧角文化的写照。鲁迅借“我”的狼狈，讽刺的不只是京剧，更是这种围着明星转的城市趣味。

紧接着那本日本书的插叙是一个精巧的过渡。书里说中国戏锣鼓喧天、跳跃激烈，在剧场里看令人头昏，若在野外空旷处远远看去，倒自有风致。“我”读了深以为然，因为他想起自己确实在野外看过一回好戏。这一段把前半的“批判”接到后半的“回忆”上，也悄悄埋下了一个线索：同样的戏，换个地方、换个距离，滋味就不同。好坏原来不全在戏本身。
:::

::: yuanwen
**第三部分**：回忆转到童年，“我”随母亲回外祖母家所在的平桥村消夏，和村里的孩子一起掘蚯蚓、钓虾、放牛，正盼着去邻村赵庄看社戏，却雇不到船。
:::

::: jiedu
笔调一下子变了。前面是拥挤的戏园，这里是靠海的小村，住户不满三十家，种田打鱼，只有一家小杂货店。“我”在这里是贵客，因为按当地风俗，出嫁的女儿夏天要回娘家消夏，带来的孩子就成了全村的客人。孩子们虽是同辈，有的按辈分算还是“我”的叔子甚至太公，但大家打起架来照样平等，没有谁会搬出“犯上”的大道理。

这个细节很有意思。鲁迅在别的作品里反复批判过尊卑长幼的礼教秩序，可在平桥村的孩子堆里，这套秩序暂时失效了。他写“我”在这里不用念那些艰深的古书，一个城里来的少爷，在钓虾放牛上反倒处处不如乡下孩子，被他们笑话也毫无怨言。这是一个被童年和乡野保护起来的小小乌托邦。

“社戏”是什么？绍兴一带的“社”原指土地神，春秋两季村镇集资演戏酬神，演员多是流动的戏班，戏台临水搭建，观众多半坐船来看。平桥村太小，自己演不起，每年要和邻村合伙，在赵庄演。所以看社戏对孩子们来说是一年里的头等大事。偏偏这一年，大船都被雇走了，“我”急得不肯吃饭，外祖母和母亲也无可奈何。小说用这一层挫折把期待拉满。
:::

::: yuanwen
**第四部分**：双喜提议用八叔的航船，由一群孩子自己撑去，担保会照顾好“我”，大人同意了；孩子们摇船出发，夜色中驶向赵庄。
:::

::: jiedu
双喜是这群孩子里的头领，聪明、有担当。他看出外祖母担心的是没有大人跟去，便拍胸脯说自己这一伙人水性好、会撑船，还写过保证一般地承诺看完就回。鲁迅特意写到大人们被说服了，这说明在这个村子里，孩子的能力是被信任的。

接下来的夜航是全篇最美的文字，也是中国现代散文里被反复称道的一段。鲁迅写两岸豆麦和河底水草散发出的清香，夹在水汽里扑面而来；月色朦胧，远处连绵的山像踊跃的铁兽脊背，一齐向船尾跑去；隐隐约约有横笛的声音，宛转悠扬。这些描写不是装饰，它们是“我”心情的外化：船行得越快，心越飞扬，世界也越明亮。

值得体会的是这段的感官层次：先是嗅觉，然后是视觉，最后是听觉。整个夜晚被写成一个逐渐展开的梦，而梦的尽头，就是赵庄的戏台。
:::
